# 🛒 E-Commerce Sales Trends Analysis

## 📌 Project Overview
This project analyzes e-commerce sales data to identify sales trends, evaluate product performance, and understand customer purchasing behavior. The objective is to generate actionable business insights that support data-driven decision-making and improve sales performance.

## 🎯 Business Objectives
- Analyze sales and revenue trends over time.
- Identify top-performing products and categories.
- Evaluate customer purchasing patterns.
- Analyze regional sales performance.
- Identify opportunities to improve profitability and business growth.

## 🛠️ Tools & Technologies
- SQL – Data extraction and analysis
- Microsoft Excel – Data cleaning and preliminary analysis
- Power BI – Interactive dashboard development

## 📊 Key Analysis Areas
- Monthly and quarterly sales trends
- Product and category performance
- Regional sales analysis
- Customer purchase behavior
- Revenue and profit analysis

## 📈 Key Performance Indicators (KPIs)
- Total Sales Revenue
- Total Profit
- Total Orders
- Average Order Value (AOV)
- Profit Margin
- Sales Growth Rate

## 💡 Business Insights
- Identify high-performing products and categories.
- Evaluate seasonal sales patterns.
- Compare regional sales performance.
- Identify products and regions with growth opportunities.
- Support business decisions through data-driven recommendations.

## 📂 Project Structure
- `data/` – Dataset used for analysis
- `sql/` – SQL queries and analysis scripts
- `excel/` – Data cleaning and analysis files
- `dashboard/` – Power BI dashboard files
- `README.md` – Project documentation
